# Array Practice Problems

## Basic

1. Find the sum of all elements in an array.
2. Find the largest element.
3. Find the smallest element.
4. Count even and odd numbers.
5. Search for an element in an array.

## Intermediate

1. Find the second largest element.
2. Reverse an array without using another array.
3. Count the frequency of each element.
4. Remove duplicate elements.
5. Find the missing number from an array.
6. Find duplicate elements.
7. Move all zeroes to the end.
8. Merge two sorted arrays.

## Advanced

1. Rotate an array by K positions.
2. Find the maximum subarray sum.
3. Find the pair with a given sum.
4. Find the intersection of two arrays.
5. Find the majority element.
6. Find the longest consecutive sequence.
7. Find the subarray with a given sum.

## Challenge

Solve the following without using built-in sorting:

- Find the second largest element.
- Remove duplicates.
- Rotate an array.
- Find the maximum element.
- Find the missing number.

Try to solve each problem with the best possible time and space complexity.
