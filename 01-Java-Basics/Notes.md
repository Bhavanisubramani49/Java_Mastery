# Java Basics Notes

## Introduction

Java is a high-level, object-oriented, platform-independent programming language developed by Sun Microsystems (now Oracle).


## Java Architecture

- JDK (Java Development Kit)
- JRE (Java Runtime Environment)
- JVM (Java Virtual Machine)



## Program Structure

Every Java program contains:

- Class
- main() method
- Statements



## Variables

A variable is a named memory location used to store data.

Example:

```java
int age = 20;
```



## Data Types

### Primitive

- byte
- short
- int
- long
- float
- double
- char
- boolean

### Non-Primitive

- String
- Array
- Class
- Interface



## Type Casting

- Explicit Casting
