# Java Basics Practice Problems

## Easy

- Print "Hello World"
- Print your name
- Print your college name
- Print your address
- Print multiple lines



## Beginner

- Store student details using variables.
- Swap two numbers.
- Calculate simple interest.
- Convert Celsius to Fahrenheit.
- Calculate area of a circle.



## Intermediate

- Read student details using Scanner.
- Calculate total, average and percentage.
- Find ASCII value of a character.
- Perform type casting.
- Demonstrate command-line arguments.



## Challenge

Create a Student Information Program that accepts input from the user and prints a formatted report.
