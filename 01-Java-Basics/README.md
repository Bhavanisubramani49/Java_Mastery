# Java Basics

This section covers the core fundamentals of Java programming. It provides the foundation required to understand object-oriented programming and advanced Java concepts.

## Topics Covered

- Introduction to Java
- JVM, JRE and JDK
- Java Program Structure
- Variables
- Data Types
- Type Casting
- User Input
- Comments
- Escape Sequences
- Command Line Arguments

## Learning Objectives

After completing this module, you will be able to:

- Understand Java architecture.
- Write and execute Java programs.
- Use variables and data types effectively.
- Accept user input from the console.
- Perform type conversion.
- Build simple console applications.
