# Control Statements

This module demonstrates how Java control statements are used to make decisions and control program execution.

## Topics Covered

- if
- if-else
- Nested if
- else-if ladder
- switch
- for loop
- while loop
- do-while loop
- break
- continue

## Learning Objectives

After completing this module, you will be able to:

- Make decisions using conditional statements.
- Execute repetitive tasks using loops.
- Solve real-world programming problems.
- Control program flow efficiently.
