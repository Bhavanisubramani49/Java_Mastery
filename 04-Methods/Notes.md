# Methods Notes

## Definition

A method is a block of code that performs a specific task.

## Types

- No Arguments, No Return
- Arguments, No Return
- No Arguments, Return
- Arguments, Return

## Advantages

- Code Reusability
- Easy Maintenance
- Better Readability
- Modular Programming

## Interview Concepts

- Static vs Instance Methods
- Method Overloading
- Call by Value
- Recursion
