# Methods Practice Problems

## Basic

1. Create a method to print your name.
2. Create a method to add two numbers.
3. Create a method to calculate the square of a number.
4. Create a method to check whether a number is even or odd.
5. Create a method to find the maximum of two numbers.

## Intermediate

1. Create a method to calculate factorial.
2. Create a method to check whether a number is prime.
3. Create a method to reverse a number.
4. Create a method to check whether a number is a palindrome.
5. Create a method to generate the Fibonacci series.
6. Create a method to calculate the sum of digits.
7. Create a method to find the greatest common divisor of two numbers.

## Method Overloading

1. Create overloaded methods to calculate the area of a circle, rectangle, and square.
2. Create overloaded methods to calculate the sum of two, three, and four integers.
3. Create overloaded methods that accept different data types.

## Challenge

Create a calculator using separate methods for:

- Addition
- Subtraction
- Multiplication
- Division
- Modulus

The `main()` method should call the appropriate method for each operation.
