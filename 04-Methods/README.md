# Methods

This module explains how methods improve code reusability, readability, and modularity in Java applications.

## Topics Covered

- Method Declaration
- Method Calling
- Parameters
- Return Type
- Method Overloading
- Pass by Value
- Static Methods
- Recursive Methods

## Learning Objectives

After completing this module, you will be able to:

- Create reusable methods.
- Pass arguments to methods.
- Return values from methods.
- Reduce code duplication.
- Solve problems using modular programming.
